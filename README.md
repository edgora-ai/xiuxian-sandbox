# 云梦洞天 · Cloud Dream Realm

> 修仙版的「我的世界」——一个可以长期游玩、不断积累、自由创造的清新唯美修仙沙盒。

**一款游戏，三种乐趣：**
- 🌄 **探索洞天**：漂浮的仙山、发光的灵矿、云雾中的秘境，每一寸土地都藏着机缘
- ⛰️ **创造洞府**：方块建造 + 阵法机关 + 傀儡自动化，从一间茅屋修到一座仙宫
- ⚡ **逆天修行**：炼气筑基结丹元婴，打妖兽攒修为，渡天劫破境界，一步步飞升

**项目状态**：调研与设计阶段（本仓库为策划案）
**美术方向**：卡通 · 清新唯美 · 水墨淡彩 · 精致粒子特效

## 一句话设计

**「把修仙的浪漫装进我的世界的自由里」**——采集灵矿、开辟灵田、炼丹炼器、布阵御兽，从练气期的一介散修，把一座荒山经营成你的洞天福地。
探索路上还有那一点点让人心痒的**机缘**：灵蝶引路、坐化洞府、掌天瓶级的天缘——稀少到值得讲给朋友听。
