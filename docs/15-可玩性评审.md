# 15 · 可玩性评审（目标玩家视角 · 诚实版）

> 评审基准：目标玩家 = **凡人修仙传粉丝 + 修仙爱好者**（参照画像：读过凡人/看过凡人动画、玩过一念逍遥或愿尝试、多为单机向、乐意为"养成积累"付费时间）。
> 本评审只回答两个问题：**能不能玩起来？玩起来好不好玩？** 结论前置，论据在后。

## 总评

| 维度 | 评级 | 一句话 |
|---|---|---|
| 设计闭环完整性 | ★★★★☆ | 探索→积累→突破→创造四环互喂，没有断环 |
| 对凡人粉的命中率 | ★★★★☆ | 境界/机缘/心机/妖丹全中，但缺"开局即韩立"的落地 |
| 爽点密度 | ★★★★☆ | 爽点清单扎实，节奏靠摩擦预算保证 |
| 好玩的最大变数 | ★★★☆☆ | **战斗手感与内容密度是执行风险，不是设计风险** |
| 差异化 | ★★★★★ | "修仙×创造沙盒"市面上没有竞品，阵法自动化是独门武器 |

**一句话结论：设计上成立且契合受众，可以进入原型；真正要赌的是执行——开局 2 小时的落地设计与战斗手感。**

## 一、受众命中率对照（凡人粉会买账的点）

| 凡人粉的核心渴望 | 设计对应 | 命中 |
|---|---|---|
| "我想当韩立：苟、算计、跑路" | 心机系统（敛息/扮猪吃虎）+ 天机 AI 反算计 | ✅ 命中要害，市面修仙游戏几乎没人做"被算计的世界" |
| "我想要我的掌天瓶" | 天缘系统：时流瓶（灵田 4 倍速）等唯一神器 | ✅ 直接的精神图腾 |
| 境界/瓶颈/破境丹 | 突破系统（成功率+丹药+天劫演出） | ✅ 教科书级还原 |
| 妖兽猎杀换妖丹材料 | 妖兽生态 + 妖丹三用途 | ✅ |
| 法宝情结 | 本命法宝养成线（11 层次品阶） | ✅ |
| 种田/炼丹的踏实感 | 灵田+四艺+离线积累 | ✅ |
| 傀儡术/御器飞行 | 傀儡自动化 + 金丹御器 | ✅ |
| 尔虞我诈的江湖 | 众生系统（恶人恩人） | ✅ 但执行难度全项目最高 |

**结论：受众的"身份幻想"覆盖完整。凡人粉看到宣传词里"敛息藏境界、掌天瓶级天缘、AI 会算计你"，会想点进来。**

## 二、六个诚实发现（按严重度排序）

### 🔴 发现 1：开局 2 小时没有专门设计（最大缺口）

- 现状：03 文档说"误入洞天的凡人少年 + 青卷残页"，仅此一句。**凡人粉对开局的记忆是青牛镇→七玄门→墨大夫→神秘小瓶**——他们也一定会用这个标准要求我们。
- 影响：沙盒游戏首两小时流失率最高。体系再对味，开局无聊就死。
- 修正案（需新增《16-开局与新手弧线》设计）：
  - 从**凡人（未入门）**玩起：0~30 分钟是"凡人少年"体验——砍柴/偶遇传功/检测灵根（抽卡时刻）/得到青卷残页第一页
  - 第一个机缘（坐化洞府）绑定在 90 分钟内，第一只灵兽 sighting 在 2 小时内
  - 开局地点固定脚本化（青牛镇式小村），此后才放开沙盒——**先给小说体验，再给沙盒自由**

### 🔴 发现 2：战斗手感只有框架，没有灵魂（执行风险）

- 现状：06 文档定义了敌人/技能/打击感三件套，但"每 30 秒一次的战斗是否有趣"没有任何原型验证。凡人粉对动作要求不高（一念逍遥是放置），但狩猎循环（打怪升级）占修为来源 55%——**战斗无聊 = 升级无聊 = 游戏无聊**。
- 修正案：M1 里程碑必须包含"战斗手感垂直切片"验收：3 种武器 × 5 种妖兽 × 30 分钟狩猎循环的盲测有趣度。低于"想再来一只"即回炉。

### 🟡 发现 3：内容密度是沙盒的生死线，路线图偏乐观

- 现状：9 群系/40 妖兽/百级配方，对 Minecraft 类是**起步量**。我们的对冲手段正确（玩家创造+自动化=自产目标，Terraria 模式），但 M2"10 小时不空转"的验收对纯种田流仍未验证。
- 修正案：每个里程碑增加"内容密度审计"：统计玩家每小时遭遇的"新东西数"（新方块/新妖兽/新配方/新事件），基线 ≥3/小时。

### 🟡 发现 4：道侣/同伴系统完全缺失（受众明显期待）

- 凡人粉的记忆点必有南宫婉/紫灵——**道侣与挚友是这个受众的高频渴望**，当前设计零覆盖。
- 修正案：不必做恋爱模拟，做**道侣/同伴系统**：众生系统的高好感 NPC 可结为道侣/道友（并肩战斗、洞府同住、各有道途自行成长、专属剧情线）。与驭兽/傀儡形成"三种陪伴"梯度。建议排期 M3 后，但架构上众生系统需预留"同伴"行为模式。

### 🟡 发现 5：修为经济只有一个静态表（节奏风险）

- 现状：09 数据表给了修为需求曲线，但"玩家实际获取速率"取决于战斗/探索/挂机的真实配比——没有动态验证。境界门槛 ×6/×20/×60 的指数曲线，若中期内容供给不足就是坐牢。
- 修正案：M1 起埋点遥测（单机本地统计），每境界实际用时 vs 设计用时偏差 >40% 即调参；准备"修为通胀"应急预案（师门任务/渡劫挑战等高阶修为出口）。

### ⚪ 发现 6：画风与题材的调性缝合需要规范

- 卡通清新 vs 夺舍/杀人夺宝的黑暗题材，处理不好会精神分裂。参照一念逍遥：Q 版不等于幼稚，**黑暗内容用"水墨留白+旁白叙事"表达，不用直白血腥**。已在 07 美术指南补一条调性规范。

## 三、爽点清单验收（每 2 小时游戏时间应至少命中 1 项）

| 爽点 | 来源系统 | 频率预期 |
|---|---|---|
| 突破演出（白光灌体/天劫雷雨） | 04 | 每数小时 |
| 机缘发现（洞天初开光柱） | 10 | 首日必中，此后数日一次 |
| 反杀/扮猪吃虎（纨绔跪了/宿敌闭嘴） | 11/12/14 | 每周数次 |
| 灵兽结契/育灵出新 | 06 | 每周 |
| 自动化上线（阵法/傀儡替你打工） | 05 | 每大境界 |
| 建成（浮空岛/仙宫落成） | 05 | 长线节点 |
| 图鉴集齐/称号解锁 | 04/10 | 持续细水 |

**判定：爽点管线健康，无断供区间——前提是审计（文档 13）的修正全部执行。**

## 四、最终裁定

1. **可玩？** 是。四大循环闭合，无逻辑死锁；M0-M1（世界+修行）技术上沿用已验证架构，原型风险低。
2. **好玩？** 对目标受众**大概率好玩**——因为它卖的是"凡人粉的身份幻想"（我即韩立）+ "我的世界式的自由"（我建洞天），两个愿望都是强需求且当前市场无竞品。
3. **最大赌注**：不在设计在执行——开局弧线、战斗手感、内容密度三件事决定成败，均已列入修正案与里程碑验收标准。
4. **建议动作**：优先补《16-开局与新手弧线》设计；M0 原型同步做战斗手感切片；道侣系统写入路线图 M3+。

> 本评审为设计期自查。真正的裁判是 M1 垂直切片的第一批玩家——凡人粉只有一个标准：**"我玩的时候，像不像在写我自己的《凡人修仙传》。"**
