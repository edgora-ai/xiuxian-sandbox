# 10 · 机缘系统（探索的"钩子"）

> 目标：让玩家在探索时抱着"万一呢"的心态多走一步——**像抽卡一样上瘾，但靠脚步不靠钞票，且极度稀少**。
> 心理学本质：变率强化（variable-ratio reinforcement）。修仙小说里这叫**机缘**；我们的任务是把"韩立捡到掌天瓶"的那种心跳，做成系统。

## 1. 设计铁律

1. **稀少是价值本身**：大机缘全世界限数量（按种子生成上限），天缘级每存档有且仅有几条
2. **货币是风险不是钱包**：机缘只能靠"去更远、更险、更新"的地方换，绝不出售、绝不做付费抽卡
3. **上瘾靠悬念不靠频率**：多给"感应/线索/差一点"，少给"真开出"——期待感比奖励本身更钩人
4. **开出必成传说**：大机缘全服可见的演出与炫耀通道（社交放大器）
5. **保底防挫败**：隐藏的气运值暗中积累，久未出货则下一发必中大以上——玩家只觉得"运气来了"

## 2. 机缘四阶（概率即价值）

| 阶 | 名称 | 单次跟随线索出现率 | 内容示例 | 稀缺约束 |
|---|---|---|---|---|
| 小机缘 | 灵物 | 30% | 一丛三株百年灵芝 · 小灵石矿囊 · 流落的货郎（便宜卖稀有种子） | 无硬限，受发现度调节 |
| 中机缘 | 遗泽 | 12% | **坐化修士洞府**（遗骨+遗物+一段生平故事）· 天外陨铁 · 迷失的商队 | 每个区块群限 1~2 处 |
| 大机缘 | 传承 | 2.8% | 功法真解/阵法孤本/灵兽卵/古宝/秘境残钥——**带专属获取小任务链** | 全世界按种子限量（如古宝 ≤6 件） |
| 天缘 | 造化 | 0.2%（且需三段线索集齐） | **掌天瓶级唯一神器**：改变一条核心规则的成长型至宝（如"灵田时流瓶：洞府作物以 4 倍速生长"） | 全存档仅 3 条，跨周刷新线索，独立剧情线 |

- 空欢喜（其余 ~55%）：也要给东西——一缕灵气、一段风景彩蛋、一句石碑诗（集齐石碑诗有隐藏奖励），**让"没出"也不空手**

## 3. 感应与线索（钩子的三个层次）

### 层次一 · 机缘感应（钩你出门）
- 进入**新发现**的区域时，隐藏气运值判定；触发时播放极轻的**玉铃声 + 一只灵蝶/流萤**从身后掠过
- 跟随灵蝶（会停顿、会犹豫、偶尔消失一段再出现）→ 抵达"机缘点"或扑空
- 同一群系连续触发递减（推着你换地图）；家附近权重趋近于零；**危险区域权重 ×3**

### 层次二 · 线索物（钩你动脑）
- **残图**：秘境/妖兽掉落残破地图碎片，集齐 3 张拼出真位置（伪位置会挖出"前人遗刻"：差一步的怅然——设计好的差一点）
- **传闻**：NPC 喝醉后说漏嘴的只言片语（对话题图鉴收集）；魔修身上搜出的手记
- **异象**：满月夜远处山脊偶尔闪过一道非自然光——走近才有答案

### 层次三 · 天缘（钩你整个版本）
天缘走**三段式传说任务链**（例：残瓶 → 瓶身刻文指向沉湖 → 湖心守灵妖 → 认主动画）：
- 三段线索分别来自大机缘、传闻网、领主首杀——把三条游戏线拧成一条执念
- 认主演出全服公告位（"道友 [ID] 于云雾峰底得【太虚时流瓶】"），别人看得见、拿不走

## 4. 稀缺与防膨胀机制

| 机制 | 规则 |
|---|---|
| 新地判定 | 同一地点的机缘只结算一次；重复探索不触发（防刷点） |
| 时距阀 | 感应最短间隔 8 分钟；单日大机缘 ≤1 |
| 世界限量 | 大机缘/天缘数量写进世界种子，挖完即无（后期版本扩充才增加） |
| 隐藏保底 | 气运值：每次扑空 +1，中机缘 +3，清零重计；气运满(≈12)时下一次感应必出大机缘以上 |
| 气运外显 | 气运值不完全显示——只在洞府"问道碑"上给模糊评语（"近日气机勃发"），保留玄学感 |
| 反付费 | 气运与机缘不进任何商店，不与充值挂钩（健康长线的底线） |

## 5. 演出与炫耀（社交放大）

- 大机缘开启：**洞天初开**演出——云雾翻开、金光垂落、异宝悬浮 3 秒特写，方圆百米可见光柱
- 获得物进**藏宝阁**有专属展台与描述考据文案（"此瓶曾盛过一界春水"）
- 机缘图鉴：每条机缘收录故事残页，集齐一章解锁称号（"云梦拾遗人"）
- 洞天帖分享时藏宝阁一并展示——别人参观洞府时，你的"当年那一次"是展品

## 6. 数值初稿（原型录入）

```
感应触发：新区块入场 2.0%（同群系连续 ×0.6；危险区 ×3；洞府半径 300m 内 ×0.1）
跟随结果：小 30% / 中 12% / 大 2.8% / 天缘线索 0.2% / 其余=空欢喜 consolation
气运值：初始 0，上限 12；保底结算在"感应成功触发"时消耗
时距阀：感应 CD 480s；大机缘日限 1；天缘任务链不占日限
```

## 7. 与其他系统的咬合

- **灵气潮汐**：潮汐夜感应率 ×2——"满月出门寻宝"成为玩家自发仪式
- **驭兽**：嗅宝鼠类灵兽可提升感应半径（灵兽的战斗外价值）
- **风水评分**：洞府风水高 → NPC 传闻质量提升（好风水带来好消息）
- **图鉴/成就**：机缘图鉴独立成章，是"积累"支柱的展示柜
