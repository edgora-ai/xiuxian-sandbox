# 14 · 众生系统（恶人与恩人 · 活的 NPC）

> 需求：要有一批 AI 恶人来**压迫、嘲笑、偷袭**（且可以反制），也要有**善良的人**递来消息与机缘。
> 关键约束：**所有人都见人下菜碟、都不固定**——NPC 不是任务发放器，是"有名字、有脾气、有记性、有自己日子要过"的人。
> 底层复用文档 11 天机系统的【洞悉】：NPC 眼中的你 = 外显境界 + 财帛 + 行为史 + 你和他的恩怨账。

## 1. 活人架构：身份卡 + 恩怨账 + 议程

世界按种子生成一批**常驻角色**（约 12~20 个有名有姓的），每个角色三张牌：

```
身份卡：姓名 · 道途/境界 · 性格原型 · 私人目标(议程) · 一个秘密 · 一条底线
隐藏意图：真正的目的未必是表面的那个（恩人可能有所图，恶人可能有苦衷）——可被探灵/事件/深交逐步揭开
策略风格：风险偏好 · 耐心 · 贪婪 · 道德 · 学习力 五维参数 → 决定他的行为手法与执行力（会犯错）
恩怨账：与你的恩/怨值 · 畏惧值 · 兴趣值 · 事件记忆（你救过他/抢过他/羞辱过他，逐条记名）
议程表：他自己在过日子——突破、寻宝、跑商、寻仇……按自己的日程在世界里移动做事
```

- **见人下菜碟的双重含义**：他怎么对你，取决于 ①他**观察到的你**（和天机 AI 同一套可见信号，禁止读档）②他的**性格滤镜** ③你们的**恩怨账**。同一个恶人，对财帛外露的低阶玩家敲诈勒索，对深不可测的敛息者点头哈腰——重开一局，众生百态全部重排。
- **不固定**：角色会死（被你杀/被别人杀/寿终）、会崛起、会洗白、会黑化。世界不为任何人停留，空出的生态位会长出新角色。

## 2. 恶人图鉴（压迫的四种风味，皆可反制）

### 恶人原型 A · 欺软怕硬的纨绔（压迫型）
- **行为**：在必经路口收"过路费"，抢你挖到的矿，带着护卫狐假虎威；你弱他踩，你强他跪
- **见人下菜碟**：只挑外显境界低的下手；遇到敛息的你 = 撞铁板的名场面
- **反制**：交钱忍气 / 当街动手（他护卫有阵型，先杀阵眼）/ 收集罪证报镇魔司（用官方刀杀人）/ 敛息伏击——打服后他**畏惧值暴涨**，日后见你绕道甚至送礼讨好
- **弧线**：被打服→收敛或转 intermediate 宿敌；被他爹（金丹老怪）寻仇 → 中期剧情自然长出来

### 恶人原型 B · 阴狠的猎宝人（偷袭型）
- **行为**：你开出大机缘被他瞧见光柱后，开始**尾随**（远处的黑影、营地的脚印）；选你最容易松懈的时刻偷袭——渡劫时、钓鱼时、重伤撤离时
- **见人下菜碟**：情报决定目标——他只偷"看得见宝贝"的人；你藏得好（敛息/空冥石假货）他就换目标
- **反制**：反侦察符/分光阵哨戒 → 反向设伏（移祸江东符+空冥石钓鱼）；他偷你成功过一次就会**盯上你的库房**——家防就此有了意义
- **弧线**：偷袭失败三次 → 他把你写进"不能惹名单"卖给同行（恩怨外溢成世界事件）

### 恶人原型 C · 嘲讽型宿敌（心理压迫型）
- **行为**：专挑你的**失败时刻**出现：突破失败来冷笑、被妖兽追着跑时在远处哈哈大笑、留嘲讽信；从不偷袭，要赢你赢得"名正言顺"
- **见人下菜碟**：嘲讽内容**引用你真实的历史**（"上次筑基失败躺三天的就是你吧"——恩怨账记忆调用），对不同玩家嘲讽点完全不同
- **反制**：斗法台正面对决（赢他=他倾佩值反转，变"不打不相识"的挚友/执念宿敌）；无视他→他升级挑衅直到自取其辱；用事实打脸（你突破成功当天送他观礼帖）
- **弧线**：宿敌养成是本作最好的长线关系——从嘲讽到并肩，全看你回应对待的方式

### 恶人原型 D · 伪善的"前辈"（阴谋型，最危险）
- **行为**：主动示好收你为"记名弟子"，赠丹药、传"功法"（实为养蛊敛灵的邪功）、帮你建洞府（在阵眼里动手脚）——时机成熟时夺舍/夺取机缘
- **见人下菜碟**：只骗**有机缘特征**的玩家（机缘光柱/新得古宝）；对一穷二白的散修毫无兴趣
- **反制**：探灵符照功法异常 / 观察他给的功法修炼时是否有黑气 / 将计就计喂假消息；揭发他 → 宗门声望大涨；私下解决 → 杀孽入账（心黑者缘浅）
- **弧线**：被骗玩家损失惨重但**恩怨账给他记下死仇**，复仇线自带三幕剧

## 3. 恩人图鉴（善意也要见人下菜碟）

### 恩人原型 A · 卖消息的散修（情报商）
- **行为**：出现在茶棚/夜里篝火旁，卖机缘线索、妖兽情报、"最近有魔修盯上你"的提醒
- **见人下菜碟**：**价格看你**——财帛外露者收三倍，落魄者"这次请喝碗茶就行"；杀孽重的人他报价里加"风险费"甚至直接卖假消息（他也在看人下菜碟，双向的）
- **深度**：他卖的消息有小概率是魔修放的饵——**消息本身也是一种心机博弈**（买不买？信不信？）

### 恩人原型 B · 试炼的老师父（拜师线）
- **行为**：想要拜师？他不白教——给一场**专门为你定制**的试炼：剑修去斩守阵妖、灵植夫去救活一座枯灵田、阵修去破一座残阵
- **见人下菜碟（善意版）**：试炼难度与形式随你的道途与短板生成——他"看人下菜碟"的方向是**因材施教**
- **反制（防御性）**：试炼可拒绝，可拖延，无惩罚——善意不给压力

### 恩人原型 C · 受恩者（善因善果）
- **行为**：你救过的人会在关键时刻出现：报信（"有人在打听你"）、雪中送炭（重伤时递丹药）、多年后带着机缘线索回来还恩
- **见人下菜碟**：恩怨账记名——你救过 5 个人的话，你的"善名"会在 NPC 间流传，善意 NPC 对你初始好感+、恶人对你声望忌惮；反过来恶名昭彰者连茶棚都拒你入内

### 恩人原型 D · 云游的隐士（稀世善意，接近机缘系统）
- **行为**：极低概率在深山遇见，不问你要什么，只聊天；若你**气运/善行达标**且触了他的兴头，留下一段口诀/一份阵图/一句天机——说完就走再也找不到
- **见人下菜碟**：杀孽重、满身铜臭的玩家遇到他，他只拱手："道友请了。"——**善意本身就是门槛**（与文档 10/12 的气运体系同源）

## 4. 反制的公共设施（"可以反制"的系统性保障）

| 工具 | 来源 | 破什么局 |
|---|---|---|
| 分光阵+警铃 | 阵法系统 | 偷袭、夜探 |
| 探灵符/神识探查 | 符箓 | 伪善前辈、化形、敛息伪装 |
| 傀儡替身 | 炼器阁 | 偷袭第一刀 |
| 移祸江东/空冥石 | 符箓 | 反向钓鱼 |
| 镇魔司/宗门告官 | 声望体系 | 纨绔、恶霸（借官方刀） |
| 斗法台 | 宗门 | 嘲讽宿敌（用实力说话） |
| 恩怨账查询 | 图鉴·众生录 | 随时查看"谁恨你、谁欠你、为什么"——信息对称，反制才公平 |

**众生录**：常驻角色的档案页——身份、恩怨账、他的议程、与你的事件时间线。玩家可以主动经营关系（送礼/助拳/结仇），NPC 会根据你的行为整体校准对你的态度。

## 5. 动态规则（"不要固定住"的实现清单）

- **议程驱动**：每个 NPC 有私人目标（突破/寻宝/报仇），按自己的日程在世界里移动——你会在妖兽山撞见正在猎潮的纨绔，在拍卖行碰到出货的猎宝人
- **记忆与引用**：对话引用恩怨账真实事件（嘲讽引用你上周的真实失败）——台词模板 + 记忆槽填充，不需要大语言模型
- **生死与迭代**：NPC 可死亡、可离开、可洗白黑化；死一个补一个（新角色继承部分恩怨网络）——世界是活的
- **与天机同源**：NPC 对你的判断走同一套【洞悉】信号与可见性规则——你骗 AI 的方式就是 AI 骗你的方式（文档 11 的公平原则）
- **气数预算**（文档 11）：压迫/偷袭受导演预算限频——恶可恨，不可烦

## 6. 数值初稿

```
常驻角色池：14±4 名（按世界种子生成），恶:恩 ≈ 5:4（其余中立路人）
恩怨账容量：每人记录最近 20 条与玩家相关事件，权重半衰期 10 游戏日
压迫触发：纨绔/猎宝人受气数预算约束，单角色对玩家主动压迫 ≤1 次/2 游戏日
嘲讽引用：失败事件后 72 游戏时内到场概率 60%（突破失败必到一次——这是他的"职责"）
善意触发：受恩者报恩间隔 ≥5 游戏日；隐士全存档出现 ≤3 次
```

## 7. 与其他系统的咬合

- 文档 11 天机系统：共用【洞悉】观察层；恶人异变与众生压迫共享气数预算
- 文档 12 心机系统：敛息/易容/探灵符既是玩家骗 AI 的工具，也是识破 NPC 的工具——同一套矛与盾
- 文档 10 机缘系统：恩人递线索、恶人身上搜手记、宿敌决斗赌注——众生是机缘的"人间出口"
- 文档 06 守山模式：纨绔搬来救兵袭击洞府 → 守山波次有了"仇恨的脸"

## 8. 自主与意图：他们也活在自己的道途上

> 核心信念：**NPC 不是为玩家而活的任务点，是各自道途上的行人。**
> 他们有自己的隐藏意图、自己的修行进度、自己的方法与策略——而且方法和策略**五花八门、也不一定对**。

### 8.1 隐藏意图（表里不一的深度）

每个角色的"秘密"升级为**隐藏意图**——驱动其一切长线行为的真动机：

| 角色 | 表面 | 隐藏意图（示例） | 揭开方式 |
|---|---|---|---|
| 卖消息的散修 | 图财 | 女儿中了噬灵咒，攒钱买续命丹——只对仁善玩家酒后吐真言 | 深交/尾随/翻他账本 |
| 嘲讽型宿敌 | 狂傲 | 父亲只认天才，他必须踩着一个"同辈天骄"证明自己 | 斗法台赛后对话 |
| 纨绔 | 跋扈 | 家族灵脉枯竭，他被迫用霸道撑住排场——纸老虎 | 探灵镜照出他的空虚根底 |
| 伪善前辈 | 慈祥 | 夺舍续命（必隐藏极深） | 探灵符+两条以上反常证据 |
| 云游隐士 | 无欲 | 在寻找能托付衣钵的传人——气运即面试 | 通关他的三次"偶遇" |

- 意图**可被发现也可永远错过**：揭开后可利用（拿捏把柄）、可成全（帮宿敌之父认可他 → 化敌为友）、可无视
- 意图会随事件**演变**：仇恨洗成执念、报恩变成守护——恩怨账 + 意图双轨演化

### 8.2 自主修行（NPC 也升级，世界在流转）

每个常驻角色跑一份**轻量修行账本**（离屏抽象模拟，不入场景不耗性能）：

```
修为来源：他按自己的议程行动 → 猎兽/挖矿/跑商/闭关 各有修为入账
突破判定：攒满后按他自己的时机尝试——吃不吃丹、挑不挑时辰，看他的策略风格与财力
结果入世界：突破成功 → 回来复仇的纨绔更强了 / 突破失败 → 气海震荡，拍卖行多了个变卖家产的人
装备流转：他赚钱会换装备，败家会卖传家宝——拍卖行的货架上，是众生的人生
```

- **世界因此有牛人**：可能有个 NPC"韩立"闷声突破比你快——拍卖行里你买不起他出的货，斗法台上他是黑马。世界不围着玩家转，才有追赶与较劲的真实感
- 你能**干预**他们的进程：救他一命/卖他假丹/在他突破时派妖兽捣乱（天劫时偷袭在文档 11 里是合法战术）——众生录记录你对每个人修行史的"干预痕迹"

### 8.3 方法不一定对（失误设计的艺术）

给每个角色一份**策略风格五维**（风险/耐心/贪婪/道德/学习力），驱动决策启发式 + 执行噪声（失误率）。**优柔寡断、贪小失大、孤注一掷——都是特性，不是 bug：**

| 策略原型 | 行为画像 | 典型失误（玩家可观察、可利用） |
|---|---|---|
| 赌徒型 | 不吃丹硬闯突破、孤身探凶险地 | 突破失败气海震荡被你撞个正着；倾家荡产押某场斗法 |
| 冲动纨绔 | 买高价丹充场面、以势压人 | 被别的 NPC 骗子坑（世界骗所有人，不只骗玩家）；砸钱买的"古宝"是赝品 |
| 执念复仇者 | 十年磨一剑只为寻仇 | 修为停滞、众叛亲离——你可以递刀也可以劝阻（他听不听看你们恩怨） |
| 苟道散修 | 永不出手、稳健攒钱 | 错过所有机缘，五十年还在炼气——但你要是在他地盘闹事，护山阵教做人 |
| 天才骄子 | 学什么会什么、进步飞快 | 骄傲自满，轻敌冒进——唯一的破绽 |

- **失误产出玩法**：救援落难修士（恩情）/ 捡尸赌徒的遗物（机缘）/ 低价收破产纨绔的传家宝（商业）/ 替执念者完成复仇（长线任务）——**NPC 的错误就是玩家的机会**，这是"世界活着"的最大证明
- **失误有下限**：五维参数保证没人蠢到自毁人设（伪善前辈不会当街行凶）；关键剧情节点 AI 失误被导演层压制

### 8.4 性能边界

- 离屏角色跑抽象账本（每游戏日一次结算，纯数值）；**入屏才实体化**为完整 AI
- 同屏完整模拟角色 ≤4；其余以"远影"状态存在（远处剪影 + 简化行为）
- 全部账本可序列化进存档——众生的人生也是存档的一部分
