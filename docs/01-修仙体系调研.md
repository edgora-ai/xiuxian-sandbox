# 01 · 修仙体系调研

> 目的：梳理网文/短剧中已成"公共语言"的修仙设定，作为游戏系统的世界观与数值参照。
> 玩家看懂任何一个系统名称的瞬间就应该知道它大概是什么——这是修仙题材最大的资产。

## 1. 境界体系（游戏进程骨架）

网文圈最通行的模板源自《凡人修仙传》，境界分**下 / 中 / 上**三段，对应人界 → 灵界 → 仙界：

| 阶段 | 境界 | 游戏定位（对应"时代/科技层"） |
|---|---|---|
| 下境界 | **炼气**（1~13 层） | 新手期：采集、建造、基础四艺 |
| 下境界 | **筑基** | 发展期：解锁灵田/驭兽/符箓，进入真正沙盒循环 |
| 下境界 | **金丹（结丹）** | 中期：炼器自动化、御器飞行、开启秘境 |
| 下境界 | **元婴** | 后期：傀儡军团、第二元神、跨区域探索 |
| 下境界 | **化神** | 终局前：改天换地级创造（地形神通） |
| 中境界 | 炼虚 → 合体 → 大乘 | 资料片层级（灵界） |
| 上境界 | 渡劫 → 飞升 → 真仙… | 终局目标：渡劫成功即"通关"，转入无尽模式 |

- 每个境界分**初期 / 中期 / 后期 / 大圆满**，炼气期分 13 层——天然的细分进度条
- **寿元设定**（凡人 ~500 年/元婴）可转化为轻压力机制：境界越高寿元越长，死亡/闭关的代价感
- 境界差距是硬门槛：**越阶挑战=高风险高回报**，这是战斗与建造双线的共同张力

## 2. 灵根（角色的"基因"）

- 五行灵根：**金木水火土**；变异灵根：**冰雷风**（+光暗稀有）
- 纯度决定资质：五系伪灵根 → 三系真灵根 → 一系天灵根，属性越少修炼越快
- 游戏化：开局抽灵根（可重抽/后天改命道具）→ 决定功法亲和、灵植亲和、抗性
  - 火灵根：炼丹效率+、火系法术强化；水灵根：灵田浇灌+、水下呼吸…
  - 五行相生相克直接用于战斗克制表与灵田轮作

## 3. 丹符阵器「四艺」（职业与自动化核心）

修仙世界的"科技树"，全部可游戏化：

| 四艺 | 修仙设定 | 游戏对应 |
|---|---|---|
| **炼丹** | 丹药 1~9 品；增修为/破瓶颈/疗伤/延寿；有丹毒副作用 | 消耗品制造系统：回血、修行加速、突破概率丹、战斗药剂 |
| **炼器** | 法器→法宝→灵宝→仙器（下/中/上/极品）；滴血认主 | 装备制造：武器/法器/飞行器/本命法宝（成长型装备） |
| **符箓** | 符师四等九级；一次性卷轴类法术 | "附魔/卷轴"系统：给方块/装备/自身附加一次性效果 |
| **阵法** | 阵法师四等九级；阵旗阵基布阵，禁制封印 | **功能方块 + 逻辑机关**（= 红石定位）：聚灵阵、护山阵、传灵阵、自动阵 |

## 4. 妖兽（打怪升级的对象）

《凡人修仙传》模板：**1 级妖兽 ≈ 炼气期，逐级对应修士境界**，共 13 级，每级分初/中/顶阶。

游戏化：
- 妖兽按境界分层刷新在对应危险度区域（练气玩家去低阶灵林，元婴去万妖山脉）
- 掉落：**妖丹**（炼丹材料/驭兽喂食）、**材料**（皮骨血炼器）、**灵石**
- 生态化：领地、夜行/昼行、周期性**兽潮**（塔防式事件）

## 5. 法宝与灵石（经济与积累）

- 法宝 11 层次：法器 → 符宝 → 法宝 → 本命法宝 → 古宝 → 通天灵宝 → 玄天之宝
  - 游戏化：**本命法宝**=唯一成长型装备，跟随主人升级、喂材料进阶、可以"炼化"独特词缀
- **灵石**=硬通货（下品/中品/上品/极品，1:100 兑换），既是货币也是修炼燃料
- 灵石矿脉 = 世界里的"钻石矿"，灵脉浓度决定区块价值

## 6. 宗门与族类（社交与阵营）

- 正道 / 魔道 / 妖族三分；散修 vs 宗门
- 宗门玩法：拜师（NPC 导师=任务线）、贡献点（宗门商店）、大比（PVP 赛季）
- 族类：人族、妖族（可化形）、古族/魔族（后期资料片）
