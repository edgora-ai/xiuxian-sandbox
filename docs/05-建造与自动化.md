# 05 · 建造与自动化（"我的世界"部分的核心）

> 原则：**建造要美，自动化要有修仙味**。
> 红石的对应物是"阵法"，村民/机器人的对应物是"傀儡"——整套自动化体系用修仙语言重新发明。

## 1. 方块建造

- 体素方块 + 半块/楼梯/斜坡；材质走"清新卡通"路线（见文档 07）
- 特色结构方块：
  - **御风石**：其上方 3 格内建筑可浮空（浮空仙岛的正确打开方式）
  - **月华晶**：夜间自发光（冷白光），满月时更亮
  - **翠玉瓦 / 朱漆梁 / 白玉阶**：高级建筑套材（金丹后解锁配方）
- 建筑**无结构疲劳**（不塌方），但**有风水评分**（见下）——鼓励美观而非硬抗力学
- 洞府范围（玩家领地）：初始 32×32，境界扩容；洞府内防妖兽刷新、可设准入

### 风水评分（把"好看"变成数值）

系统按规则给建筑评分：对称性 / 屋檐曲线 / 错落高度 / 水景环绕 / 花木点缀 / 灯光层次。
风水越高：修炼速度、灵田生长、NPC 访客频率提升。**颜值即收益**，这是"画面清新唯美"的玩法化。

## 2. 阵法系统（= 红石 / 自动化核心）

阵法 = **阵基（方块）+ 阵旗（可插方块）+ 阵盘（配置界面）** 组成的功能区。

| 阵法 | 功能 | 对应 MC 概念 |
|---|---|---|
| 聚灵阵 | 吸收周围灵气存储入灵池 | 发电/储能 |
| 行雨阵 | 范围内灵田自动浇灌生长 | 自动农场 |
| 引灵阵 | 把远处矿脉"牵引"到阵眼缓慢产出 | 洞口采矿机 |
| 护山大阵 | 洞府护罩，抵御兽潮/魔修 | 防御塔 |
| 传灵阵 | 两点传送（阵眼对码） | 传送门网络 |
| 幻踪阵 | 阵内隐身/误导妖兽寻路 | 陷阱 |
| 聚音阵 | 播放自定义音乐/警报到远端 | 红石音乐/警报 |
| 分光阵 | 区域监视，画面投射到阵盘 | 摄像头 |

**阵法逻辑层（进阶，元婴解锁"阵道合一"）**：
阵基间可用**灵纹线**连接，组成条件触发（灵池满→驱动傀儡；妖兽进圈→鸣警报+护山阵启动）。
本质是一套轻量可视化逻辑门（与/或/非/计时/阈值），界面做成"符文拼图"，不暴露布尔术语。

## 3. 傀儡（= 自动化劳力）

- 获得：傀儡图纸（遗迹/宗门）+ 材料（寒铁/傀儡核）在**炼器阁**组装
- 类型与升级：采集傀（挖矿伐木）→ 看火傀（炼丹辅助）→ 巡山傀（自动战斗哨兵）→ 玲珑傀（跟随保姆：搬运/分类入箱）
- 行为：可指派"工牌"（工作区域 + 任务优先级）；吃灵石（续航）——玩家要设计"傀儡排班"
- 外观：Q 版圆润机器人，玩家可涂装（呼应卡通画风，收集党抓手）

## 4. 灵田与灵牧场（种田流）

- 灵田：灵土 + 灵种，浇灌/灵气/季节影响；**轮作相生**（水生灵植滋养相邻火系+10%）
- 灵牧场：驯服的温和妖兽（玉兔产毛、云牛运货、灵鸡产蛋）圈养产出
- 产出全部可入库；**库房带分类灵架**（玩家最爱的收纳装饰两用方块）

## 5. 四艺工坊（制造系统）

| 工坊 | 产物 | 玩法深度 |
|---|---|---|
| 炼丹房 | 丹药（回血/增修为/突破率/战斗药剂） | 丹方收集 + 火候 QTE + 丹炉品级；失败出"药渣"可再利用 |
| 炼器阁 | 法器/装备/傀儡部件/飞行器 | 材料词条池（灵纹镶嵌）+ **本命法宝养成线** |
| 符箓台 | 符箓（火球符/金光符/遁地符/定身符/行雨符） | 符纸+灵墨绘制；贴方块=机关，贴自身=增益 |
| 阵法台 | 阵旗/阵盘/阵基 | 阵法解锁与升级（见上） |

- 制造普遍**挂机可成**（离线进度），QTE 只是加速——尊重长线积累
- 所有配方在图鉴中可见获取途径（不搞黑箱）

## 6. 飞行与移动（创造自由度）

- 炼气：奔跑/跳跃 + 轻功（二段跳）
- 筑基：御器滑翔（滑翔翼手感，落霞林夜景名场面）
- 金丹：御器飞行（自由飞行，坐骑外观可换：飞剑/纸鸢/莲台）
- 元婴：瞬移（短距 blink，建造定位神器）
- 化神：**神通改地形**——移山填海/引水成湖/唤起成林（创造模式的修仙表达）
