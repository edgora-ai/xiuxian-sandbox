# 06 · 战斗与灵兽

> 战斗定位：**轻动作 + 技能轮盘**，不是硬核 ACT——重点在"打得爽、掉落香、图鉴收集"。
> 敌人三类：野外妖兽（生态）· 魔修袭击者（阵营 PVE）· 秘境守卫（副本）。

## 1. 战斗手感（3C 基准）

- 普攻：御器近战（剑修）/ 法术远程（法修），命中带顿帧 0.05s + 粒子反馈
- 法术快捷栏 4 格（键盘 1-4 / 手柄十字键），冷却转盘走"灵光回流"演出
- 闪避：轻功位移（i-frame 0.3s），体力条独立于法力
- 打击感三件套：受击白闪 + 击退 + **妖兽血条用"灵气环"呈现**（环形受伤剥落，不用扁平血条）

## 2. 妖兽生态

| 层级 | 示例 | 行为 | 掉落 |
|---|---|---|---|
| 一阶（练气） | 玉兔/赤狐/竹叶青 | 温和或胆小，被打才反击 | 一阶妖丹/皮毛 |
| 二阶（筑基） | 青猿/铁背狼/云雕 | 群体巡逻、有头目 | 二阶妖丹/兽骨 |
| 三阶（金丹） | 火蟒/冰蛟/岩甲犀 | 领地性强、有技能前摇提示 | 三阶妖丹/妖兽内腑 |
| 领主级 | 各群系 1 只（如焚火山·炎狮王） | 多阶段 Boss，场景互动 | 古宝残片（必掉）/图鉴 |
| 特殊 | 蛟龙（化神）、上古傀儡 | 世界事件刷新 | 传说法宝 |

生态细节：领地标记、昼夜活动差异、**兽潮**（每 5 游戏日一次，月圆夜涌向玩家聚居区——守山玩法）。

## 3. 驭兽与灵兽（积累线之二）

- **结契**：把妖兽打到残血 → 用缚灵索 → 喂妖丹好感到 100 → 结契成功（失败率看兽阶与御兽栏等级）
- 灵兽 = 可养成伙伴：跟随战斗（4 技能位）· 产出道具（牧场模式）· **骑乘**（二阶起）
- 融合玩法：同系两只灵兽可"育灵"出下一代（继承技能池，卡通外观可遗传配色）
- 图鉴：灵兽图鉴画满后该系**驯服率永久提升**——收集即成长

## 4. 秘境（副本内容）

- 世界随机刷新**秘境之门**（存续 2 游戏日），或用遗迹残钥开启固定秘境
- 结构：3~5 个房间 + 机关谜题（阵法解谜，服务创造向玩家）+ 领主房
- 奖励：功法书/丹方/阵法图纸/古宝——**版本新内容的投放渠道**
- 可单人可组队；每周首通双倍

## 5. 守山模式（致敬红警的塔防事件）

兽潮来袭时，玩家可切换**指挥视角**（俯视小地图）：
- 在护山大阵内布置符箓炮塔/傀儡哨兵/陷阱阵
- 波次制防守 5~8 波，守住得灵石雨 + 领主积分
- 平时不影响沙盒节奏——**想打就打，不想打就跑图**，模式开关自由

## 6. 魔修袭击（PVE 阵营对手）

- 血煞门会周期性"踩点"：侦察（黑衣人窥探，可跟踪反打）→ 袭击（护山阵考验）
- 反攻玩法：攻打魔修据点（小型巢穴副本），夺回被掳灵兽/资源
- 长线：魔道声望系统——也可以走魔修路线（血炼功法，赚快但掉正道声望，双修路线分歧）
