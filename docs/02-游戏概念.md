# 02 · 游戏概念

## 定位一句话

**修仙版的《我的世界》**：以"修行境界"为进程骨架、以"积累与创造"为乐趣核心的长线沙盒游戏。
卡通清新画风，浏览器/移动端即开即玩。

## 三大支柱（所有设计向这三条对齐）

### 支柱一 · 长期游玩（有盼头）

- **境界即版本**：炼气→筑基→金丹→元婴→化神，每个大境界是一次"世界扩容"——解锁新区块群系、新方块、新配方、新机制（御器飞行、神通改地形）
- 目标感永远存在：短目标（今晚炼出聚气丹）、中目标（攒齐筑基丹三味药材）、长目标（渡劫飞升）
- **赛季化长线**：飞升不是结束，飞升后开启灵界内容 + 图鉴收集 + 仙宅装修

### 支柱二 · 积累（存得下）

- 一切劳动都能沉淀：灵石灵矿入库、灵田四季轮作、妖兽材料分类囤积
- **洞府**是玩家的成就陈列馆：从茅屋到仙宫，从杂物的堆放到藏宝阁的镇派之宝
- 数值永远在涨：修为条、寿元、妖兽图鉴、丹方收集——**离线也在积累**（挂机吐纳/灵田生长）

### 支柱三 · 创造（玩得自由）

- 方块建造 × 修仙想象力：浮空岛用**御风石**、发光用**月华晶**、自动灌溉用**行雨阵**
- **阵法 = 本作的红石**：可编程的功能方块系统（见文档 05）
- **傀儡 = 本作的村民/机器人**：采集、炼丹看火、守卫，可外观自定义
- 创造作品可一键生成"**洞天帖**"分享给其他玩家参观（蓝图社交）

## 核心循环

```
        ┌──────────── 探索（寻灵矿/药园/秘境/妖兽） ────────────┐
        ↓                                                      │
   采集与狩猎 ←─ 战斗成长（打怪得修为/妖丹/材料）                  │
        ↓                                                      │
   修炼突破（攒修为 → 突破境界 ← 用丹药/灵石提高成功率）           │
        ↓                                                      │
   解锁：新方块 · 新配方 · 新阵法 · 新区域 · 新机制               │
        ↓                                                      │
   建造与自动化（洞府扩建 · 阵法机关 · 傀儡产线 · 灵田农场） ──────┘
```

双螺旋成长：
- **人修**（角色境界）：打怪/服丹/吐纳攒修为 → 突破 → 解锁玩家能力（飞行/神通/四艺等级）
- **家修**（洞府等级）：建造/自动化产出 → 支撑更快的修炼 → 反哺境界推进

## 目标玩家

| 人群 | 诉求 | 钩子 |
|---|---|---|
| 修仙网文读者（核心） | "我想亲自修行" | 境界/丹符阵器全套体系原味还原 |
| 沙盒玩家 | 创造与自动化 | 阵法机关 + 傀儡产线 |
| 轻度/女性玩家 | 唯美画风、无压力 | 卡通清新、可纯种田零战斗 |
| 短剧用户 | 熟悉的爽点节奏 | 突破/渡劫/打脸妖兽的即时演出 |

## 体验原则（写进验收标准）

1. **清新不黑暗**：失败代价是"重伤回洞府"，不删档不爆仓（死亡掉落可选）
2. **每一分钟都有进账**：修为条永远在动，采集必有产出，探索必有发现
3. **界面说人话**：所有修仙术语配白话副标题（聚灵阵 · 自动收集周围灵气）
4. **单机优先**：全程可离线，联网才解锁参观/交易等社交层
