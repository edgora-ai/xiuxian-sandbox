# 07 · 美术风格指南

> 关键词：**卡通 · 清新唯美 · 水墨淡彩 · 精致特效**。
> 一句话：像"宫崎骏的水彩画 + 一念逍遥的 Q 萌 + 光遇的光"——明亮、柔和、有仙气，绝不阴间。

## 1. 总体视觉锚点

| 维度 | 定调 | 忌讳 |
|---|---|---|
| 体形 | Q 版二头身（人物）、圆润几何（妖兽/建筑） | 写实肌肉、尖锐棱角 |
| 色彩 | 高明度中低饱和 + 大面积留白（云雾） | 高饱和撞色、脏暗色调 |
| 光照 | 柔光 + 体积雾 + 泛光克制 | 硬阴影、恐怖打光 |
| 线条 | 卡通描边（细、深青灰 #2a3b47） | 黑色硬描边 |
| 氛围 | 灵气粒子常驻（萤光/花瓣/雾霭） | 空气感空白 |

## 2. 色板（主世界基调）

```
青瓷绿  #7FB88A   主色·植被/UI 主底
云雾白  #F4F7F5   天空/留白
霞光粉  #F2B8C6   晚霞/花瓣/点缀
黛蓝    #4A6FA5   远山/夜空
灵光青  #9FE8E0   灵气粒子/法术特效基色
暖黄    #F5D48A   灯火/丹药/丰收
墨青灰  #2A3B47   描边/文字
```

- 五行各有主题色系（金·鎏白 / 木·青瓷 / 水·黛蓝 / 火·霞橙 / 土·赭黄），UI 与特效按系取色
- 群系在统一色板上做"色彩偏移"而非换套色——保证世界像一幅完整的画

## 3. 造型语言

- **方而不僵**：体素方块 + 倒角/圆边处理（方块圆润化是卡通感第一步）
- **人物**：二头身、飘带衣袂（随风动画常驻）、发型是识别核心（发簪/发带免费自定义）
- **妖兽**：圆眼短肢、幼态比例；敌意靠"瞳色变红 + 低伏姿态"表达而非狰狞
- **建筑**：飞檐翘角、纸灯笼、竹帘——中式构件卡通化，轮廓圆润
- **图标**：圆底 + 单体剪影 + 灵光点缀；术语配白话小字

## 4. 特效规范（"制作精良"的标准）

| 类型 | 规范 |
|---|---|
| 灵气粒子 | 常驻环境粒子（萤光上升流）；密度与区域灵气浓度挂钩 |
| 法术 | 起手聚气 0.2s → 释放拖尾 → 命中绽花（三段式，禁止一帧爆炸贴图） |
| 突破演出 | 天地灵气漩涡吸入 → 白光灌体 → 环形冲击波 + 花瓣雨；天劫为紫金雷柱 |
| 采集 | 命中碎屑按材质配色，采集完成一圈灵光收束入手 |
| UI 动效 | 卷轴展开/墨滴晕开/符纸燃转；单一动效 ≤0.4s |
| 预算 | 同屏粒子 ≤600；每个特效必须有低配降级路径（数量减半，样式不减） |

**特效审美三原则**：① 白/青为主彩色为辅 ② 曲线运动无直线弹道 ③ 所有特效自带"仙气尾迹"。

## 5. 音画配套

- BGM：笛/古筝/空灵吟唱的环境仙乐，白天竹海版/夜晚月下版同曲变奏
- 音效关键词：风铃、水滴、剑鸣、丹炉火——所有 UI 点击用"玉磬"轻响
- 昼夜与四季带环境音变化（夏蝉/冬雪静默）

## 6. 界面（HUD）风格

- 半透明"玉简"面板：圆角 + 淡青底 + 墨青描字，全部术语有白话注释
- 小地图做成**罗盘玉盘**；血条蓝条做成环绕人物脚下的"灵气环"
- 通知用"传音飞剑"动画从屏外飞入（1s，可跳过）
