# 11 · 天机系统（见人下菜碟的自适应 AI）

> 概念：怪会针对你的功法下菜、敌人会设反转、灵兽会反水——通过**简单的规则推理**触发"异变"事件。
> 设计底线一句话：**AI 只读你在世界里的表现，不读档、不开天眼；每一次针对都有征兆、有破绽、有解法。**

## 1. 为什么这套 AI 配修仙题材

- 修仙小说的爽点就是**算计与反算计**：韩立流的"苟、算计、跑路"。敌人会学习、会伪装、会反咬，游戏才有"江湖不是打打杀杀，是人情世故"的味道
- 五行相克天生就是"被针对→再反制"的语言：AI 针对你 = 逼你真的去用五行系统（教学藏在敌意里）
- 灵兽反水 = 驭兽系统的张力来源：契约有重量，忠诚才珍贵
- 涌现故事是最强的传播素材（"我的灵兽半夜叼着我的丹药跑了"）

## 2. 四层架构（简单推理，不搞黑科技）

```
观察层【洞悉】 → 推理层【天机盘】 → 执行层【异变表】 → 节奏层【气数】
```

### 2.1 观察层 · 洞悉（只收集"世界内可见"的信号）

| 观察项 | 采集信号（全部是世界内合理可见的） |
|---|---|
| 功法五行画像 | 最近 30 场战斗的元素伤害占比、常用法术槽 |
| 战斗习惯 | 近战/远程比、走位距离（风筝率）、药品使用频率、逃跑倾向 |
| 生活轨迹 | 常走路线、灵田位置、出门时辰、洞府防御薄弱侧 |
| 灵兽状态 | 忠诚度、妖性、饥饿、受伤未治、被迫攻击同族次数 |
| 财帛外露 | 装备品阶（外观可见）、洞府灯火山水（风水外显） |

❌ 禁止：读取背包/存档/设置等"天眼"数据。AI 知道的，必须是**它看得见的**——被发现"作弊"是自适应 AI 的死刑。

### 2.2 推理层 · 天机盘（加权规则表，可枚举可调试）

不是机器学习，是一张不断更新的**"对你画像"权重表**：
`火系 62% · 远程风筝 71% · 常走东岭 · 灵兽"小黑"忠诚 41% · 财帛外露：金丹中期装备`
每条规则形如：`IF 目标火系占比>50% AND 连续3场 → 激活"克火"异变候选池`。
权重随时间衰减——**AI 会"忘记"**：你换了功法，旧的针对会在几场战斗后失效（给"洗流派"留活路）。

### 2.3 执行层 · 异变表（三类异变）

#### A. 功法克制（怪的下菜碟）
| 你的习惯 | 怪的异变 | 破绽（可学习） |
|---|---|---|
| 主火系 | 狼群获得**水灵庇护**光环（受火伤-40%）| 光环呈水蓝波纹；雷/土系照常克制它们 |
| 主剑修近战 | 赤狐习得**灵狐三退**（后跳拉开距离放风筝） | 第三次后跳必硬直 0.5s——预判它 |
| 满血硬吃伤害 | 岩甲犀解锁**破甲冲**（无视 30% 防御） | 冲锋前刨地 0.8s，侧闪触发撞墙自伤 |
| 总靠药品续命 | 新词条**血煞虫**：攻击附加"禁药"（3s 内喝药无效） | 虫在妖兽头顶飞，可优先点杀 |

克制**跨战斗遗传**：被你反复猎杀的狼群，下一代狼王携带"抗火"词条——你在一个区域的猎杀史，塑造那个区域的物种。图鉴会记录这条演化链。

#### B. 敌人反转（魔修的算计）
- **假投诚**：重伤魔修求收留→ 成为洞府杂役，数日后趁你外出**偷丹药/开阵眼**。前兆：眼神闪躲、半夜不睡、阵旗被动过（可早发现：问询/搜身/只给假钥匙）
- **装死反咬**：妖兽血条空了"倒地"，头顶没有妖丹飘出=装死，靠近触发扑杀——教玩家"补刀"
- **领主复仇**：被你打残逃走的领主会**结疤归来**（外观带疤、带走你当时掉落的物品装备着）——你的战利品挂在它身上，就挂在它的巢穴里
- **调虎离山**：袭击你的灵田引你出门，真目标是洞府库房（家里的巡山傀儡和护山大阵此刻就是答案）

#### C. 灵兽反水（忠诚的重量）

> **默认关闭**（审计修正，见文档 13）：反咬式背叛对收集型玩家是纯负体验。默认行为为温和版——
> 忠诚过低时灵兽**出走**（蹲在山门方向告别式发呆 → 回山林，可追踪找回、喂食招回），不攻击主人。
> 完整反水（含反咬）仅在**魔道剧本/硬核模式**开启。三段征兆与预防逻辑两种模式通用：

```
忠诚度因子：饥饿 − / 带伤作战 − / 被迫攻击同族 −− / 喂养与抚摸 + / 心契丹 ++ / 放生反而 +
征兆一（抗拒）：指令延迟执行，战斗中召回要喊两次
征兆二（妖性显）：夜里眼睛泛红光，开始偷吃灵田
征兆三（出走前夜）：白天蹲在山门方向发呆 —— 此时可「深谈」救回
出走事件：夜里叼走你库房一件东西回山林（可追踪找回；找到后选择：严惩/原谅——原谅则忠诚大增）
反水事件（仅魔道/硬核）：夜里反咬主人，本命契约（金丹解锁）可完全免疫但全场仅一只、缔结需天材地宝
```

### 2.4 节奏层 · 气数（AI 导演，防"被针对到恶心"）

- 异变消耗**气数预算**：每次异变扣预算，预算随现实时间与游戏事件缓慢回充——松紧交替，绝不连招
- **新手保护**：炼气期只开"功法克制"类温和异变；反水/反转在筑基后才解锁
- **力 catching**：若玩家连续重伤 2 次，天机盘自动调低针对强度（暗中，不给提示）
- **剧情敌人豁免**：关键叙事 Boss 不受随机反水干扰，按剧本演出
- **离线封山**（审计修正，见文档 13）：袭击洞府类事件仅在玩家在线时发生；离线期间洞府自动进入封山状态——**出门远征不必为家焦虑**

## 3. "敌变我也变"（把针对变成教学）

每次 AI 异变生效时：
- 异变体**外观必有破绽**（光环色/新增肢体/行为前摇）——观察是核心技能
- 青卷残页（引导系统）弹出一句提示而非答案："水灵庇护……听说土能克水。"
- 图鉴新增【异变志】：记录你触发过的每一种 AI 异变及其克制法——**收集 AI 的进化史**
- 玩家反制成功（用克制系击杀 5 只异变体）→ 该区域种群"改回"原属性：世界在你手里流动

## 4. 数值与开关初稿

```
洞悉采样：每场战斗结算一次画像，权重半衰期 = 5 场
异变触发：气数预算满 + 画像阈值达成；单区域同时异变种类 ≤2
克火类改词条概率：狼群代际遗传 25%/代，封顶 60%
灵兽反水：忠诚 <35 持续 3 游戏日 + 妖性>60 → 出走前夜事件
气数预算：上限 100，异变消耗 20~45，回充 1/分钟游戏时
总开关：设置中可关闭"反转/反水"类（保留功法克制），无障碍友好
```

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 玩家觉得"AI 读心作弊" | 只用世界内可见信号 + 图鉴公开全部异变逻辑（规则透明） |
| 反水/反转令人挫败 | 三段征兆 + 总开关 + 新手期豁免 + 气数预算限频 |
| 数值失控（AI 越针对越强） | 异变只改"属性倾向/行为"，不叠加数值成长；词条有封顶 |
| 调试困难 | 天机盘权重表可视化（调试面板），异变全部落日志 |

## 6. 与其他系统的咬合

- **五行/灵根**：克制异变让五行战斗语言真正被"教"会
- **驭兽**：忠诚系统因此有牙齿；"心契丹"成为高价值消耗品
- **机缘系统**：魔修手记/领主巢穴是机缘线索的天然来源——AI 的"算计"也能开出机缘
- **守山模式**：AI 导演用气数预算调度兽潮强度，波次构成针对你的防御短板
- **图鉴**：【异变志】成为硬核玩家的攻略勋章
