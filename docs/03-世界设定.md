# 03 · 世界设定

## 世界观：云梦洞天

上古大能陨落时，将一界灵气封入一方**洞天**——云雾缭绕、悬浮仙山、灵脉纵横的小世界。
玩家是误入洞天的凡人少年，得**青卷残页**（引导系统/叙事者）指点，从这里开始修行。
洞天没有尽头：境界越高，揭开的天幕越远（世界边界随境界扩张）。

## 世界结构（垂直 + 环状）

```
        ☁ 云海之上 · 浮空仙岛群（金丹+ 御器飞行可达）· 上古遗迹
   ─────────────────────────────────────────────
        云梦主世界：环状大陆，由内向外危险度递增
        内环 · 洞府盆地（安全区，玩家自选洞府选址）
        中环 · 灵田平原 / 青竹海 / 落霞林（练气~筑基）
        外环 · 万妖山脉 / 焚火山岭 / 寒潭冰原（金丹~元婴）
   ─────────────────────────────────────────────
        🌊 地下世界：灵矿层（竖井挖掘）→ 幽冥水府 → 地心岩浆域
```

| 群系 | 视觉关键词 | 特产资源 | 妖兽 | 危险档位（软门槛） |
|---|---|---|---|---|
| 灵田平原 | 嫩绿+流光萤点 | 灵稻/清心草、软土 | 玉兔/野猪（温和） | 安宁 |
| 青竹海 | 层叠青绿、风过竹浪 | 紫竹（炼器）/笋 | 竹叶青蛇 | 安宁 |
| 落霞林 | 橙粉晚霞色、枫叶飘落 | 落霞果、蜂蜜 | 赤狐/狼群 | 微险 |
| 云雾峰林 | 山尖浮云、瀑布 | 云母/铁精/灵茶 | 猿猴/雕 | 微险 |

| 上古遗迹（天空） | 白玉残柱、符文微光 | 阵法残卷/古宝 | 傀儡守卫 | 险中藏宝 |

**软门槛原则**：没有"境界不足禁止入内"的硬墙——任何玩家可以踏进任何区域：打得过小怪、打不过精英、**采不动高级矿（工具/境界判定）**，但可以看、可以跑、可以捡边角料、可以放下传送锚点改天再来。
渴望（差一点就能够到）比围墙更能驱动升级；危险由玩家自担，死亡不掉落（见文档 04/13）。

## 灵气系统（世界的呼吸）

- **灵气浓度**是区域属性：灵脉附近高、荒地低、聚灵阵可改变
- **灵气潮汐**昼夜与月相波动：夜晚/满月修炼效率+50%，萤火粒子明显增强（视觉=机制）
- 浓度影响：修炼速度、灵田生长、妖兽刷新率、法术威力——**选址是策略**
- 高浓度区域视觉泛淡青辉光（清新唯美的一个核心画面记忆点）

## 时间与节令

- 一日 = 现实 30 分钟（昼 20 / 夜 10）；夜晚妖兽活跃但修炼加成
- 四季轮转影响灵田：春播夏长秋收冬藏；**上元灯会 / 中秋灵潮** 等节令活动
- 寿元显示为"甲子"计数（纯氛围向，非死亡倒计时；丹药可延寿=成就感装饰）
