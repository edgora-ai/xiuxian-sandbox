# 04 · 修炼进程设计（打怪升级的骨架）

> 把修仙的"境界"翻译成游戏语言：**境界 = 内容关卡 + 能力解锁 + 数值分层的进程系统**。
> 修为 = 经验值，打怪是主要来源，修炼/丹药/任务补充。

## 1. 境界阶梯（总进度表）

| 境界 | 层级 | 修为需求(基准) | 解锁能力 | 解锁内容 | 预计游玩时长 |
|---|---|---|---|---|---|
| 炼气 | 1~13 层 | 13 段小进度 | 吐纳、基础法术 1~2 个、方寸袋(背包扩容) | 洞府选址、灵田、基础四艺 | 4~6h |
| 筑基 | 初/中/后/圆满 | ×6 | **御器滑翔**、驭兽契约、符箓使用 | 云雾峰林、驭兽栏、符箓台 | 10~15h |
| 金丹 | 初/中/后/圆满 | ×20 | **御器飞行**、金丹神通 1 选 1、炼器进阶 | 焚火/寒潭、傀儡、秘境副本 | 20~30h |
| 元婴 | 初/中/后/圆满 | ×60 | **元婴出窍**(第二视角/傀儡接管)、瞬移短距 | 万妖山深层、上古遗迹 | 40h+ |
| 化神 | 初/中/后/圆满 | ×180 | **神通改地形**(移山/引水/唤林) | 天空遗迹群、创造沙盒高阶 | 长线 |
| 渡劫 | 一~九重雷劫 | — | 飞升演出 | 灵界资料片（预留） | 终局 |

- 修为获取：打妖兽 55% / 修炼打坐 20% / 丹药 15% / 任务探索 10%
- **打怪升级曲线**：同阶妖兽=标准收益；越一阶×3 修为但伤害×2；兽潮清波有额外修为
- 每层突破有小演出（灵气灌体 0.8s 白光），大境界突破是大演出（见天劫）

## 2. 灵根（开局身份）

- 开局 roll：五行灵根（金木水火土）主副属性 + 纯度（伪/真/天）
- 作用：①对应该系法术伤害 +15/30/50%；②该系灵植生长 +；③该系矿脉可感知（高亮）
- **改命机制**：洗髓丹 / 机缘事件可洗灵根——防止开局定死劝退
- 灵根 UI 一屏讲清：五个圆点 + 白话一句（"火灵根·真：火法术更强，炼丹更快"）

## 3. 突破（风险与爽点的核心）

```
修为攒满 → 突破窗口（可随时发起）→ 三段演出：
  ① 凝聚：方圆灵气汇聚（粒子吸入，玩家选择增益词缀二选一）
  ② 判定：基础成功率（85%）− 越阶惩罚 + 丹药/阵法/时辰加成
  ③ 结果：成功 → 演出 + 属性跃升；失败 → 重伤(HP≤30%)，修为折损 20%，无其他惩罚
```

- **天劫**：金丹→元婴起，突破触发雷劫演出——3~5 道天雷依次落下，玩家可：
  - 硬抗（防御装/护盾符）· 用**引雷木**引到别处劈妖兽（机智玩法）· 逃走（判定失败）
  - 天雷落点是真实伤害判定，其他玩家/妖兽也能被劈——可被战术利用（创造与战斗的交叉点）
- 突破是玩家**主动选择时机**的事件，不是被动升级音效——它是仪式

## 4. 功法（能力树）

- 每大境界给 1 本功法位：**剑修 / 法修 / 体修 / 丹修（辅助向）** 四选一为主线
- 功法带来被动 + 主动技能槽（法术快捷栏 4 格）：
  - 剑修：御剑术（投掷回旋）、剑气斩、万剑归宗（大招）
  - 法修：火球/冰锥/落石（对应灵根强化）、护体灵光
  - 体修：金刚不坏（减伤）、撼地（范围击退）、负重的"人形矿镐"采集加成
  - 丹修：药理（丹效+）、灵手（采集必得额外掉落）、大还术（群体治疗）
- 功法书掉落自秘境/宗门贡献，可切换流派（洗点道具：忘尘水）

## 5. 死亡与寿元（轻惩罚原则）

- 死亡：重伤昏迷 → 回洞府床上醒来，掉落 30% 背包灵石（可回原地捡回包裹，10 分钟消失）
- 化神后死亡额外掉 5% 修为——高境界有代价但不毁灭
- 寿元：纯氛围系统（甲子计数 + 丹药延寿 + 结算图鉴"岁数"），不强制死亡

## 6. 打怪升级的节奏设计（反枯燥）

| 反枯燥手段 | 说明 |
|---|---|
| 猎杀目标多样化 | 同区域 3~4 种妖兽，行为模式不同（冲撞/远程/遁地） |
| 灵气潮汐轮转 | 不同时辰不同区域"灵气沸腾"——修为 ×2 引导玩家流动 |
| 妖丹用途广 | 炼丹材料 / 驭兽粮 / 法宝喂养——打怪产出永远不浪费 |
| 图鉴与猎令 | 妖兽图鉴收集 + 每日猎令（悬赏三选一） |
| 妖兽首领 | 每群系 1 只领主级（元婴级内容），首杀必掉古宝残片 |
